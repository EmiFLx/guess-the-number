# guess-the-number
 A simple game about guessing the number, made with Python.
 
A simple number guessing game made with Python.

The player has to guess a random number generated by the program.

## Features

- Easy mode
- Medium mode
- Hard mode
- Random number generation
- User input handling

 ## Difficulty Levels

- Easy → Number between 1 and 10
- Medium → Number between 1 and 50
- Hard → Number between 1 and 100

## How to Run

```bash
guess_the_number.py
```

## Technologies Used

- Python 3
